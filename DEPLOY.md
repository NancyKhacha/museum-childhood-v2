# «Музей детства» — как выложить на сайт НЭН

Спецпроект НЭН × VK Видео. Утвержденная версия от 25 ноября 2026 года. Тестовая копия работает здесь: https://nancykhacha.github.io/museum-childhood-v2/

## Что это технически

Статичный сайт без сборки и без сервера приложений: две страницы, CSS, JavaScript-модули, один JSON с текстами музея, картинки и шрифт Onest. Внешних библиотек и CDN нет, все лежит внутри.

Все пути внутри относительные, поэтому сайт работает из любой папки: `https://n-e-n.ru/museum/`, `https://n-e-n.ru/special/muzey-detstva/` или с отдельного поддомена.

- `index.html` — обложка с куклами и текст о проекте.
- `museum.html` — сам музей: 3D-коридор по пяти эпохам, 55 предметов.

## Как развернуть

1. Возьмите архив `museum-detstva.zip` из релиза на GitHub. В нем папка `site/`, этот файл и скрипт `set-site-url.py`.
2. Пропишите итоговый адрес проекта. От него зависят каноническая ссылка, превью в соцсетях, микроразметка и sitemap:

   ```
   python3 set-site-url.py https://n-e-n.ru/museum/ --dir site
   ```

   Адрес — папка, в которой будет лежать `index.html`, со слешем на конце. Скрипт заменит тестовый адрес `https://nancykhacha.github.io/museum-childhood-v2/` во всех нужных файлах. Без Python можно сделать то же поиском и заменой в `index.html`, `museum.html`, `sitemap.xml`, `robots.txt` и `site-url.txt`.
3. Загрузите содержимое папки `site/` на сервер как есть, сохранив вложенные папки.

## Настройки сервера

- Только HTTPS.
- Типы файлов: `.js` → `text/javascript` (страницы грузят JS-модули, с другим типом браузер их не запустит), `.json` → `application/json`, `.webp` → `image/webp`, `.woff2` → `font/woff2`, `.svg` → `image/svg+xml`.
- Сжатие gzip или brotli для `.html`, `.js`, `.css`, `.json`, `.svg`.
- Кэш: HTML — `no-cache`. JS, CSS и JSON подключены с меткой версии `?v=20261124-v2t`, их и картинки можно кэшировать надолго. Если потом что-то поменяется в JS или CSS, поднимите метку во всех местах, где она встречается: в `index.html`, `museum.html`, `museum.js` и `hero-gl.js`.

## Поиск и соцсети: что уже сделано

- `<title>` и `meta description` на обеих страницах.
- Каноническая ссылка. Адреса музея с `?era=…` склеиваются в `museum.html`.
- `meta robots`: индексировать, крупные превью картинок разрешены.
- Open Graph и Twitter Card с картинкой `assets/og-cover.jpg` (1200×630, обложка с куклами).
- Фавиконка и иконки для iOS и Android (`favicon.ico`, `assets/icons/`).
- Микроразметка schema.org (JSON-LD): страница, издатель «Нет, это нормально», тема — передача «Спокойной ночи, малыши!», эксперты проекта, список из 55 экспонатов музея.
- Заголовок H1 — логотип «Музей детства», дальше H2 и H3 по структуре текста. Видимые тексты и оформление не менялись.
- Текстовая версия музея. Музей строится скриптом, и его тексты появляются только после клика, поэтому в `museum.html` внутри `<noscript>` лежат все тексты музея по эпохам: вступления, цитаты экспертов, 55 предметов, история передачи и финал. Ее видят поисковые роботы и браузеры без JavaScript. Обычный посетитель ее не видит, у него все работает как раньше.
- `sitemap.xml` с обеими страницами.

## Что нужно сделать на стороне НЭН

1. **robots.txt и sitemap.** Поисковики читают robots.txt только в корне домена, поэтому файл `robots.txt` из проекта — образец. Добавьте в корневой `https://n-e-n.ru/robots.txt` строку `Sitemap: <адрес проекта>sitemap.xml` или внесите две страницы проекта в общий sitemap сайта.
2. **Вебмастер.** Отправьте обе страницы на переобход в Яндекс Вебмастере и Google Search Console.
3. **Аналитика.** Счетчик Яндекс Метрики или другой системы, которой пользуется НЭН, вставьте перед `</head>` в обе страницы: `index.html` и `museum.html`. При смене эпохи музей меняет в адресе только `?era=`, без перезагрузки страницы.
4. **Превью в соцсетях после выкладки.** Проверьте и при необходимости обновите кэш: ВКонтакте — пришлите ссылку в личные сообщения и посмотрите превью; Telegram — бот @WebpageBot; Facebook — Sharing Debugger. Микроразметку можно проверить в Google Rich Results Test и в валидаторе микроразметки Яндекс Вебмастера.

## Если поменяются тексты музея

Тексты музея лежат в `data/museum.json`. После правки в репозитории запустите:

```
python3 scripts/build-seo.py
```

Скрипт обновит текстовую версию музея и список экспонатов в `museum.html`. Потом заново соберите архив: `python3 scripts/build-dist.py`.

## Что не трогать

- `hero-math.js`, блок `DESIGN` — места кукол на обложке, перенесенные из макета в Figma («Музей детства — обложка-толпа (слои)»). На экранах 1280×800 и 390×844 куклы стоят точно по макету, на остальных расстановка растягивается между названием и краями экрана.
- Куклы прилетают по дуге и садятся на места. Если в системе включено «уменьшить движение» или браузер не поддерживает WebGL, они сразу стоят на местах обычными картинками.
